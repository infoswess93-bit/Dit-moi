# Dit-moi — практика французької

Застосунок для телефона (PWA): відкрити в Chrome на Android → меню ⋮ → «Встановити застосунок» / «Додати на головний екран». Працює офлайн.

## Структура
| Файл | Що всередині |
|---|---|
| `index.html` | каркас сторінки |
| `css/styles.css` | вигляд |
| `js/app.js` | логіка: вкладки, перевірка, рівні, картки, прогрес |
| `data/tenses.js`, `data/tenses2.js` | вправи на часи (перші уроки) |
| `data/tenses-more.js` | ще по 10 уроків на кожен час; **генерується** з `tools/items/*.txt` командою `python3 tools/gen_tenses.py` |
| `data/topics.js` | вправи «Практика» |
| `data/sets.js` | реєстр розділів: назва, списки вправ, нагадування |
| `data/gloss.js` | словник для подвійного дотику |
| `data/vocab-presets.js` | готові слова для «Словника» |
| `data/grammar.js` | довідник граматики (A1–B2) |
| `IDEAS.md` | ідеї нових функцій |
| `tools/bundle.py` | збирає все в один HTML для перегляду в Claude |

## Формат вправи
```js
{ pre: "Hier, je ", post: " mon service.", verb: "finir", tr: "Переклад", a: ["ai fini"], o: ["ai fini", "suis fini", "finis", "avais fini"], why: "Пояснення" }
```
`a`: правильні відповіді, `o`: варіанти на вибір.

**Важливо:** порядок розділів у `sets.js` і порядок списків у `lessons` не змінювати. Нові списки додавати тільки в кінець, інакше зламається збережений прогрес.

## Як додати речення на час
1. Додайте рядок у `tools/items/<час>.txt` (pc, imp, fp, fs, prs, cond, sbj): `початок|кінець|дієслово|особа|переклад`.
2. Запустіть `python3 tools/gen_tenses.py`: відповідь, неправильні варіанти й пояснення порахуються самі (таблиця дієслів у `tools/conj.py`).
